Picture guide

Connect Claude to VS Code

Go one step at a time. Each picture shows exactly where to click. The yellow circle marks the spot.

Before you start

  • A paid Claude plan. Pro or higher. The free plan does not work in VS Code. See plans
  • Your laptop and an internet connection
  • About 15 minutes
My computer is a

Step 1 of 12

Download VS Code

  1. Go to code.visualstudio.com/download.
  2. Click the download button for MacWindows.
  3. Wait for the download to finish.
Good to know

VS Code is free. It is made by Microsoft.

Step 2 of 12

Install and open VS Code

  1. Open your Downloads folder.
  2. Drag Visual Studio Code into your Applications folder.
  3. Open Applications and double-click Visual Studio Code. If your Mac asks, click Open.
  1. Open your Downloads folder and double-click the VS Code installer.
  2. Choose I accept the agreement, then keep clicking Next.
  3. Click Install, then Finish. VS Code opens.

Step 3 of 12

Open a folder for your work

  1. Click the blue Open Folder button on the left.
  2. Go to your Desktop and make a new folder named AI Workshop.
  3. Select that folder and click Open.
Why a folder?

Claude saves the files it makes for you here. You can find them later on your Desktop.

Step 4 of 12

Tell VS Code the folder is safe

  1. A box asks if you trust the authors of the files.
  2. Click Yes, I trust the authors. You made this folder, so it is safe.
Skip this?

If you click No, Claude will not work in this folder.

Step 5 of 12

Open Extensions

  1. Look at the column of icons on the far left.
  2. Click the icon made of four small squares. That is Extensions.
Shortcut

Press ⌘ Cmd Shift XCtrl Shift X together.

Step 6 of 12

Install Claude Code

  1. Type Claude Code in the search box.
  2. Click Claude Code for VS Code. Check that it says Anthropic with a blue check mark.
  3. Click the blue Install button. It takes a few seconds.
Look alikes

Other extensions use the word Claude. Only install the one from Anthropic.

Step 7 of 12

Make a blank file

  1. In the file list on the left, point at AI WORKSHOP.
  2. Click the New File icon that appears next to it. It looks like a page with a plus sign.
  3. Type notes.md and press Enter. The file opens.
Why?

The Claude button only shows up when a file is open.

Step 8 of 12

Click the orange Claude icon

  1. Look at the top right corner of your open file.
  2. Click the orange starburst. A Claude panel opens on the right.
Shortcut

Press ⌘ Cmd EscCtrl Esc together.

Step 9 of 12

Sign in

  1. The first time, the Claude panel shows a sign in screen.
  2. Click Sign in. Your web browser opens.

Step 10 of 12

Approve in your browser

  1. Sign in with the same Claude account that has your paid plan.
  2. Click the button to allow Claude Code to connect.
  3. Go back to VS Code. You are signed in.
Heads up

This page can look a little different from the picture. Look for the button that approves access.

Step 11 of 12

Ask Claude for something

  1. A short Learn Claude Code checklist may appear. Close it with the X or try it later.
  2. Click the message box at the bottom of the Claude panel.
  3. Type a request and press Enter.
Try this

Draft a one-page syllabus for my Introduction to Statistics course and save it as syllabus.md

Step 12 of 12

See the file Claude made

  1. If Claude asks permission to create the file, read it and approve.
  2. The new file appears in your file list on the left.
  3. Click it to read it. Edit anything you like.

You are all set

Claude is connected. Bring this laptop to the workshop and we will build from here.

Stuck?

Quick fixes

Tap a problem to see what to do.

I do not see the orange Claude icon
  1. Make sure a file is open. The icon only shows up next to an open file. See step 7.
  2. Still missing? Press ⌘ Cmd Shift PCtrl Shift P, type Reload Window, and press Enter.
  3. You can also click the Claude icon in the column of icons on the far left.
The extension will not install
  1. Update VS Code. On a Mac, click Code in the top menuWindows PC, click Help in the top menu, then Check for Updates.
  2. Restart VS Code and try step 6 again.
It keeps asking me to sign in
  1. Make sure you sign in with the Claude account that has a paid plan.
  2. Press ⌘ Cmd Shift PCtrl Shift P, type Reload Window, and press Enter.
The bottom bar says Restricted Mode
  1. Click Restricted Mode in the bottom bar.
  2. Choose to trust the folder. Claude needs this to work.
Claude does not answer
  1. Check that your internet is working.
  2. Close the Claude panel and click the orange icon again to start fresh.
